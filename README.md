### Do I need to disable my anticomponent?

Some security software may flag executables. You may need to add exceptions for the XCutors folder, as is common with such tools.

### How do I get updates?

Check the 'Releases' page of this repository or use the built-in updater within the loader if available.

### My anticomponent removed a file. What do I do?

This is a common false positive. Restore the file from your anticomponent quarantine and add an exclusion for the entire XCutors folder.

### The script executor isn't working with a game. Why?
